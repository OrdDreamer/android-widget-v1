Primary interactive control for actions like "Save widget" or "Add photo".

```jsx
<Button variant="primary" size="md" icon="add_photo_alternate">Add photo</Button>
```

Variants: `primary` (terracotta fill), `secondary` (sage fill), `outline` (bordered), `ghost` (text-only). Sizes: `sm`, `md`, `lg`. Pass `disabled` to dim + block interaction; press state scales to 0.97.
